# Paddi Studio · 个人介绍版

这是 Paddi Studio 的个人网站静态副本，定位为万建伟的个人介绍、作品集、开发站点和 Paddi Ecosystem。

## 页面

- index.html：欢迎页，播放品牌记忆动画视频
- home.html：个人主页与入口导航
- about.html：个人背景与能力
- portfolio.html：网站、移动端与产品项目
- contact.html：联系渠道
- sites.html：Paddi 开发的站点目录
- ecosystem.html：Paddi Ecosystem

## 本地预览

在当前目录运行 python -m http.server 9091，然后打开 http://127.0.0.1:9091/。

原始恢复目录保持不变。旧的业务入口和相关资源已移到相邻的回滚备份目录，便于回看和恢复。
